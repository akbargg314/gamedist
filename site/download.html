GameDist is pre-release. Releases are published on GitHub; this page lists the files of the latest one. Until a release exists, or for the desktop app, build from source.

What a release contains

The release workflow builds one archive per platform: linux-x86_64, windows-x86_64 and macos-aarch64 (Apple silicon). Each archive holds three programs, plus the license and README:

  • gamedist-launcher: the launcher, in its headless (command-line) mode only.
  • gamedist: the publisher CLI for developers.
  • gamedist-server: the distributor server. The Linux archive also contains the deploy files (install.sh, the systemd unit, a sample config, Caddy and nginx examples).

A SHA256SUMS file lists the checksum of every archive. The workflow is also set up to push a server container image to ghcr.io/akbargg314/gamedist-server.

Before you download

  • No desktop app packages yet. The workflow does not build installers for the desktop app (.deb, .AppImage, .msi, .dmg). If a later release has them, this page lists them automatically.
  • Windows and macOS builds are untested. Before the release workflow, nothing had been built on either; all testing so far has been on Linux.
  • Binaries are not code-signed, so your operating system may warn before running them. Check the archive against SHA256SUMS: 
    $ sha256sum -c SHA256SUMS --ignore-missing
  • The Docker image and deploy scripts have not been tested. Please report what breaks.

Games you install with the launcher are verified by the launcher itself; the launcher binary is verified by you.

Build from source

Server, CLI and headless launcher

Needs a stable Rust toolchain.

$ git clone https://github.com/akbargg314/gamedist.git
$ cd gamedist
$ cargo build --workspace --release

The binaries are target/release/gamedist-server, target/release/gamedist and target/release/gamedist-launcher (headless). Then try the launcher:

$ target/release/gamedist-launcher --headless --help

To install only the publisher CLI: cargo install --path crates/cli.

Desktop app

Needs Rust 1.90 or newer, Node.js 20+ with npm (or Deno 2), and the system webview. On Debian or Ubuntu:

$ sudo apt install libwebkit2gtk-4.1-dev build-essential curl wget file \
    libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev
$ cd gamedist/apps/launcher
$ npm install
$ npm run tauri dev      # run it
$ npm run tauri build    # or make installable bundles

Bundles land in apps/launcher/src-tauri/target/release/bundle/. Package names for Fedora and Arch, and the Windows and macOS prerequisites, are in the launcher README.

The app has been compiled and run by hand on Linux only, with npm run tauri dev. Bundling and builds on Windows and macOS are untested.
